O Hecaton não pôde iniciar

Nem toda máquina pode rodar o aplicativo.

Não foi possível reservar uma conta

Cada janela do Hecaton usa uma conta só dela, para que duas janelas nunca mexam nos mesmos perfis do navegador ao mesmo tempo. Desta vez o aplicativo não conseguiu reservar nenhuma — nem uma existente, nem uma nova.

Quase sempre é o Windows recusando o mecanismo de reserva. Feche as outras janelas do Hecaton e abra esta de novo; se continuar, reinicie o computador. O aplicativo prefere não abrir a abrir duas janelas na mesma conta, porque isso danifica as sessões salvas.

Esta parece ser uma máquina virtual

O Hecaton não roda dentro de VMware, VirtualBox, Hyper-V, QEMU e semelhantes. Se esta é uma máquina física, o fabricante gravou na BIOS um nome que parece o de um hipervisor.

Esta máquina não é a que está registrada

O Hecaton guarda uma marca do hardware em C:\ProgramData\hecaton\machine.json na primeira vez que roda, e a marca deste computador não confere com a que está gravada.

Isso acontece quando a pasta foi copiada de outro computador, quando a placa-mãe foi trocada, e também quando o arquivo existe mas não pôde ser lido. Se a máquina é sua, apague aquele arquivo como administrador e abra o Hecaton de novo: ele grava uma marca nova.
